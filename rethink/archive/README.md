# Archived experiments

Single-eye, history and superseded experiments, kept for the record. Their runs remain in
`../results/experiments.csv`; every logged configuration is still reported. The project continues on
the bilateral single-visit path only (decision 2026-11-10).

The scripts import modules from `rethink/` by their own directory. To rerun one, `git mv` it back to
`rethink/` first.
