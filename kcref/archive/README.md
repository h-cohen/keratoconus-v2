# Archive

Every experiment of the development programme (E00–E28), the code it imported, and its result tables, kept as a
record. All runs remain in `../results/experiments.csv`; `../RESULTS.md` and `../PROTOCOL.md` describe them.
These scripts import the old module layout (`harness.py`, `exp20/21/22_*.py` …) and are not maintained. The final
model is `../model.py`, with `../features.py` and `../evaluate.py`; it reproduces `exp28_tricks.py blend` exactly.
